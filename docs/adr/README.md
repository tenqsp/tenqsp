# Architecture decision records

One file per decision, `NNNN-short-title.md`, with: Context, Options considered, Measurements
(where applicable), Decision, Consequences. ADRs are never rewritten after acceptance; a later
ADR supersedes an earlier one.

For the public release (2026-10-30) the records were edited in one respect only: "the owner"
became "the project lead", and some pointers to private planning documents were removed. Where
a record still cites "the PRD" (the project's original design specification) or a spike, that
document is not part of the public repository; the section numbers are kept for the record.
